Premiers pas

Une idée. Trois gestes.

1

Posez le cadre

Ouvrez le tableau et renommez vos acteurs en double-cliquant sur les noms des couloirs.

2

Tracez le parcours

Choisissez les formes dans la palette. Ajoutez vos étapes, puis reliez-les avec les flèches.

3

Gardez une copie

Dans le menu, choisissez « Enregistrer sous… » pour le fichier BPMN ou « Exporter l’image… ».

Faut-il créer un compte ?

Non. Ouvrez le tableau et commencez à dessiner directement.

Où mon diagramme est-il sauvegardé ?

Dans les données locales du navigateur utilisé. Il revient à la prochaine ouverture de ce même tableau. Enregistrez aussi un fichier BPMN pour conserver une copie indépendante : effacer les données du navigateur efface cette sauvegarde locale.

Puis-je reprendre un diagramme existant ?

Oui. Choisissez « Ouvrir » dans le menu du tableau, puis sélectionnez votre fichier .bpmn ou .xml.

Comment partager mon processus ?

Exportez une image PNG ou SVG pour la présenter, ou enregistrez le fichier BPMN pour permettre à quelqu’un de reprendre le diagramme.
