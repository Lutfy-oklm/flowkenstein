Processia · Votre tableau BPMN 2.0

Choisissez une forme dans la palette horizontale du haut, puis placez-la sur le tableau. Le bouton ⋮ affiche les autres éléments BPMN.

Cliquez sur une forme : la flèche permet de la relier, la clé de changer son type, la poubelle de la supprimer. Le bouton + Couloir ajoute un acteur.

Double-cliquez pour écrire. Déplacez les formes librement. Utilisez Propriétés pour ajouter une description ou modifier leur taille.

Le dessin s’enregistre dans ce navigateur. Dans le menu ☰, Enregistrer sous… conserve un fichier BPMN réutilisable ; Exporter l’image… propose PNG et SVG.
