Help and getting started

Draw, connect and save your first BPMN 2.0 process.

Last updated: 13 October 2026

1. Organize participants

The canvas starts with lanes. Double-click a name to edit it. “+ Lane” adds a participant; consistent heights and alternating backgrounds make the diagram easier to read.

2. Add steps

Choose a shape from the top toolbar, then place it on the canvas. The ⋮ button provides more BPMN elements. Double-click a shape to edit its label.

3. Connect shapes

Use the connection tool or the arrow in a shape’s menu. Automatic alignment helps create straight connections when you move shapes, without showing alignment guides.

Pan, zoom and resize

Use the hand tool to pan the canvas. The mouse wheel or − and + buttons change the zoom. Handles resize tasks and lanes. When content moves out of view, “Back to content” brings it back.

Sub-processes

Open a collapsed sub-process to detail its content. “Back to the main process” returns to the original diagram. Lanes added in this view belong to the open sub-process.

Save and export

The canvas automatically saves in this browser. For an independent copy, open the ☰ menu and choose “Save as…”: the BPMN file preserves shapes, connections and dimensions. “Export image…” creates a PNG or SVG image.

Open a file

Choose “Open” in the menu, then select a BPMN or BPMN 2.0 XML file. Oversized or overly complex files and unsupported extensions are rejected. For files from other software, try a standard BPMN 2.0 export.

Switch language, device or address

The French and English canvases on the same website share the same local diagram. Switching language changes the interface without translating your own labels. Saves do not automatically transfer between browsers, devices or domains. Export the BPMN file from the old canvas, then open it in the new one.
