Contact

Une question, une suggestion ou un problème avec Flowkenstein ?

Dernière mise à jour : 13 octobre 2026

Écrire à l’éditeur

ttdesigny@gmail.com

Cette adresse reçoit les demandes d’aide, suggestions, signalements de sécurité et questions sur vos données personnelles. Le bouton ouvre votre application de messagerie ; aucun message n’est envoyé automatiquement.

Signaler un problème

Indiquez votre navigateur, les étapes pour reproduire le problème et le résultat attendu. Une capture sans information confidentielle peut aider.

Pour un problème fonctionnel, vous pouvez aussi utiliser les issues GitHub. Les messages sur GitHub sont publics : ne publiez pas de données personnelles, mots de passe ou diagrammes confidentiels.

Question de sécurité

Signalez une vulnérabilité par e-mail plutôt que dans une issue publique, afin de permettre son examen avant divulgation.

Avant de nous écrire

Consultez l’aide du tableau BPMN et la politique de confidentialité. Les diagrammes sont enregistrés dans votre navigateur ; l’éditeur ne dispose pas d’une copie permettant de récupérer un fichier perdu.
